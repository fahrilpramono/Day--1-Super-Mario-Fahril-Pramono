# Day--1-Super-Mario-Fahril-Pramono
Rangkuman Materi Git & GitHub

1. Prompt Engineering
Prompt Engineering adalah cara menyusun instruksi kepada AI agar menghasilkan jawaban yang tepat dan sesuai kebutuhan.
Struktur prompt yang baik:
  * Role: Menentukan peran AI.
  * Task: Menjelaskan tugas.
  * Context: Memberikan konteks.
  * Format: Menentukan bentuk hasil.

2. Pengertian Git
Git adalah sistem untuk mencatat dan mengelola perubahan pada file atau kode program. Git dibuat oleh Linus Torvalds pada tahun 2005.
Fungsinya untuk melacak perubahan, menyimpan riwayat, dan memudahkan pengelolaan proyek.

3. Git vs GitHub
  * Git: Alat untuk mengelola perubahan kode secara lokal.
  * GitHub: Platform online untuk menyimpan repository Git dan berkolaborasi.
  
4. Git Workflow
   Ada tiga bagian utama:
    * Working Directory: Tempat membuat atau mengedit file.
    * Staging Area: Tempat menyiapkan perubahan sebelum disimpan.
    * Git Directory: Tempat menyimpan data dan riwayat perubahan Git.

5. Istilah Penting
  * Repository: Tempat menyimpan proyek.
  * Commit: Menyimpan perubahan.
  * Branch: Cabang untuk mengembangkan fitur.
  * Pull Request: Permintaan untuk menggabungkan perubahan.

6. SSH Key
SSH Key digunakan untuk menghubungkan komputer dengan GitHub secara aman. Materi menggunakan algoritma Ed25519.

7. Praktik Student Task Planner
   Langkah pembuatan aplikasi:
    * Menggunakan AI untuk membantu membuat aplikasi.
    * Membuat prompt sesuai kebutuhan.
    * Memasukkan proyek ke Git dengan git init.
    * Melakukan commit dan push ke GitHub.
    * Mengubah aplikasi.
    * Melakukan commit dan push kembali.

Kesimpulan:
Prompt Engineering membantu kita memberikan instruksi yang tepat kepada AI, sedangkan Git dan GitHub membantu mengelola, menyimpan, serta melacak perubahan kode program
